# 1. Setup

Install the workspace and run the application locally.

## Prerequisites

Make, Bash, Git and uv on Ubuntu 22.04+ or macOS. uv provisions the Python version set by
`requires-python` in `pyproject.toml`; run `make install-uv` if uv is missing. Docker is optional and
only needed for `make docker-build`.

## Install

```bash
git clone https://github.com/AmineDjeghri/ha-addons.git
cd ha-addons/addons/personal-app
make install-dev
cp .env.example .env
```

This installs backend, frontend and dev/docs tools and, in a Git checkout, the Git hooks.
The hooks come from the repository-root `.pre-commit-config.yaml` and cover every add-on.

Before a pull request, run:

```bash
make check   # hooks, tests and the strict documentation build
```

## Run

```bash
make run
```

| URL / command                            | Use                          |
| ---------------------------------------- | ---------------------------- |
| <http://localhost:8080>                  | Frontend                     |
| <http://localhost:8000/docs>             | Backend API docs             |
| `make run-backend` / `make run-frontend` | Start either side separately |

## Home Assistant add-on image

The `Dockerfile` is the add-on image: the Supervisor builds it and starts it through `run.sh` (bashio),
so it cannot run standalone. `make docker-build` checks that it builds.

## Documentation site

```bash
make deploy-doc-local
```

## Everyday commands

| Command           | Use                                                                |
| ----------------- | ------------------------------------------------------------------ |
| `make check`      | The full local gate before a pull request                          |
| `make test-all`   | Unit tests and the built-wheel smoke test                          |
| `make pre-commit` | Run the static hooks; `FILES="path/a path/b"` limits them to files |
| `make docs-build` | Strict documentation build                                         |
| `make clean`      | Remove caches and temporary files                                  |
| `make help`       | List all targets                                                   |

## Optional environments

| Command                | Use                                                                            |
| ---------------------- | ------------------------------------------------------------------------------ |
| `make install-prod`    | Production dependencies only                                                   |
| `make install-tools`   | Quality and docs tools without the application dependencies                    |
| `make install-release` | Packaging and release tools without the application dependencies               |
| `make act`             | Run GitHub Actions locally (`make install-act` first; needs Docker and `.env`) |

For publication, see [release credentials](5.release.md#before-you-start).

## Editor and agent rules

Select `.venv/bin/python`; mark `backend/src`, `frontend/src` and `tests` as source/test roots.
